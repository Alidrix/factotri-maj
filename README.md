# Factotri — versions publiées

Ce dépôt contient uniquement les versions publiées de l'application **Factotri** (aucun code source).

L'application les télécharge d'elle-même pour se mettre à jour. Chaque version est **signée** par Factotri :
l'application vérifie cette signature avant toute installation et refuse une version modifiée ou venant d'ailleurs.
